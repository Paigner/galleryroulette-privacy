# galleryroulette-privacy

Privacy policy and auth page for GalleryRoulette, hosted on GitHub Pages at
https://privacy.galleryroulette.paigner.at/

- `index.html` - privacy policy ( en / de )
- `auth/confirm.html` - magic link landing page (shows the 6-digit code and opens the app)
- `auth/logo.png` - logo used in the email template

These URLs are linked from the app, the store listings and the email template.
